# Rios Advogados — site institucional

Site institucional responsivo, implementado em HTML, CSS e JavaScript sem dependências de build. Abra `index.html` diretamente ou sirva a pasta com qualquer servidor estático. A navegação usa rotas por hash (`#/...`).

## Antes de publicar

- Confirmar nome completo, cargo e inscrições OAB de todas as pessoas apresentadas. A página usa “Equipe jurídica” para Giovanna enquanto a qualificação não estiver confirmada.
- Substituir os blocos tipográficos de retrato por fotografias institucionais autorizadas.
- Inserir endereço, telefone, e-mail e horário de atendimento confirmados.
- Revisar a oferta e o escopo das áreas de atuação e aprovar os textos e artigos.
- Revisar a Política de Privacidade com os fluxos reais de dados. O formulário atual é demonstrativo e não envia nem armazena dados; conectá-lo a um serviço antes de receber contatos.
- A copy e as notas editoriais fornecidas são proposta de conteúdo; validar o site final com a equipe do escritório antes de publicar.

## Arquivos

- `index.html`: shell do site e metadados
- `styles.css`: identidade visual responsiva
- `app.js`: navegação, páginas e conteúdo institucional
- `assets/logo-white.png`: logotipo extraído da apresentação de identidade visual fornecida
